Claude Code plugin

Linear Issue Enricher

A Claude Code plugin I built and open-sourced. Scores Linear issues for agent-readiness and writes agent-ready specs. Matches a person's readiness call on 9 of 12 test tickets.

The problem
Tickets often lack the technical context a coding agent needs, so the agent guesses or stalls.
What I built
A Claude Code plugin that pulls an issue through the Linear MCP server, scores it 0–12 on four criteria, explores the matching repos, and writes an agent-ready spec. It asks before posting anything back to Linear. An eval checks its scores against a person's: same readiness class on 9 of 12 sample tickets, and within one point on every criterion.

Mobile app

HealthOS

A local-first health and fitness app: AI workout plans, photo food logging, and body metrics. No cloud account, no subscription.

The problem
Most fitness apps lock your data in the cloud behind a subscription.
What I built
A React Native app that keeps everything on the device in SQLite. It calls the Gemini API directly (bring your own key) to plan workouts, log food from photos, and coach from your last seven days. Component library

Tessera UI

My own design system and 71 accessible components, written once and used in React, Vue, Angular, or plain HTML.

The problem
I work across React, Vue, and Angular, and kept rebuilding the same components for each one.
What I built
One Web Components library that works in all three, so every project, from client work to pet projects, starts with the same toolkit. I shaped the design system with AI help: modeled on popular design systems, but simpler, keeping what most products actually need. It targets WCAG 2.1 AA, with keyboard support, ARIA patterns, and forced-colors mode. Three-tier design tokens drive light, dark, and high-contrast themes. Unit and end-to-end tests, a docs site, and Storybook.

Performance & SEO

This website

A fast static site: Lighthouse performance around 90 and SEO 100 on every page, on mobile and desktop.

The problem
A portfolio has to load fast, work for everyone, and be easy for search engines and AI assistants to read.
What I built
Static pages from Nunjucks templates and JSON data, built with Gulp. Sass and PostCSS with unused CSS stripped out, minified JS, HTML, and images, lazy-loaded images, and fonts that never block the page. Structured data, a sitemap, and llms.txt help search engines and AI assistants understand it. Every merge runs a GitHub Actions pipeline that lints, builds, and publishes the site to GitHub Pages, with no manual deploys.
